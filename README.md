## Entry

> Eight billion wishes every night, and nobody wished me a day off.

The Moon has heard every wish for billions of years. Nobody ever wished one for the Moon.

The joke is the reversal: every wish is for the wisher — the Moon, doing the night shift forever, never gets one back.

## How it works

`main.ts` writes the single line above to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
